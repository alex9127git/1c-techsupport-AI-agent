# Приложение 4. Перечень автоматически сохраняемых настроек

Приложение описывает настройки, которые автоматически
сохраняются платформой в системном хранилище.

## 4.1. Хранилище: вариантов отчета

Настройка: варианты отчета

●
Ключ объекта – полное имя отчета.

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```
Отчет.Продажи
```

●
Ключ настройки – текстовый идентификатор
варианта.

Пример ключа настройки:

[Копировать в буфер обмена](#_top)

```
ПродажиПоРегионам
```

●
Тип сохраняемого значения – НастройкиКомпоновкиДанных.

## 4.2. Хранилище: настроек отчета

Настройка: настройки отчета

●
Ключ объекта – текстовая строка,
составленная из полного имени отчета, символа «/» и ключа варианта.

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```
Отчет.Продажи/ПродажиПоРегионам
```

●
Ключ настройки – текстовый идентификатор
настройки.

Пример ключа настройки:

[Копировать в буфер обмена](#_top)

```
МоиКлиенты
```

●
Тип сохраняемого значения – ПользовательскиеНастройкиКомпоновкиДанных.

## 4.3. Хранилище: данные форм

Настройка: значения полей формы

●
Ключ объекта – полное имя формы.

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```
Обработка.ВыгрузкаДанных.Форма.ОсновнаяФорма
```

●
Ключ настройки – текстовый идентификатор
сохраняемых значений.

Пример ключа настройки:

[Копировать в буфер обмена](#_top)

```
ВыгрузкаВСбербанк
```

●
Тип сохраняемого значения – Соответствие.
Ключом соответствия выступает текстовый путь к сохраняемому реквизиту данных, а
значением является значение реквизита.

## 4.4. Хранилище: настроек динамического списка

Настройка:
настройки динамического списка

●
Ключ объекта – является строковым
значением, состоящим из полного имени формы и имени реквизита типа ДинамическийСписок.

Пример
ключа объекта:

[Копировать в буфер обмена](#_top)

```
Документ.ПриходТовара.Форма.ФормаСписка.Список
```

●
Ключ настройки – текстовый идентификатор
сохраняемых значений.

●
Тип сохраняемого значения – ПользовательскиеНастройкиКомпоновкиДанных.

## 4.5. Системное хранилище

Настройка: ключ текущего варианта отчета

●
Ключ объекта – текстовая строка,
составленная из полного имени отчета и строки /КлючТекущегоВарианта
(/CurrentVariantKey).

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```
Отчет.Продажи/КлючТекущегоВарианта
```

Если у формы установлено свойство КлючНазначенияИспользования, то ключ объекта
формируется следующим образом: полное имя отчета, символ "/",
значение свойства КлючНазначенияИспользования
и строка /КлючТекущегоВарианта.

Пример
ключа объекта:

[Копировать в буфер обмена](#_top)

```
Отчет.Продажи/ДляФормыНачисленияСкидок/КлючТекущегоВарианта
```

В данном примере
свойство КлючНазначенияИспользования
имеет значение ДляФормыНачисленияСкидок.

●
Ключ настройки – пустая строка.

●
Тип сохраняемого значения – произвольное
значение, содержащее ключ текущего варианта.

Настройка: ключ текущей настройки отчета

●
Ключ объекта – является строковым
значением, состоящим из полного имени отчета, ключа варианта отчета (в виде
строки) и текста /КлючТекущихПользовательскихНастроек
(/CurrentUserSettingsKey).

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```
Отчет.Продажи/ПродажиПоРегионам/КлючТекущихПользовательскихНастроек
```

Если у формы установлено свойство КлючНазначенияИспользования,
то ключ объекта формируется следующим образом: полное имя отчета, символ "/", ключ варианта отчета в виде строки, символ
"/", значение свойства КлючНазначенияИспользования
и строка /КлючТекущихПользовательскихНастроек.

Пример ключа объекта:

[Копировать в буфер обмена](#_top)

```

```

В данном примере ключ варианта отчета имеет значения ПродажиПоРегионам, а свойство КлючНазначенияИспользования
имеет значение ДляФормыНачисленияСкидок.

●
Ключ настройки – пустая строка.

●
Тип сохраняемого значения – произвольное
значение, содержащее ключ текущего варианта.

Настройка: настройки варианта отчета при закрытии отчета
